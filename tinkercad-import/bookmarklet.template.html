Tinkercad to layerling

Bring your Tinkercad design into layerling so you can keep editing it.

Use a computer for these steps. Your original Tinkercad design stays unchanged.

Set up once

  1. Show your bookmarks bar. This is the strip of saved website links just below the address bar. If you cannot see it, use the instructions below.
    BrowserWindows / LinuxMac
    Chrome, Edge or FirefoxCtrl + Shift + B⌘ + Shift + B
    Safari—Choose View → Show Favorites Bar
    Hold the keys down together. If the bar is already visible, skip this step.
  2. Save the export button. Click and hold the blue button below, drag it up onto that bar, then let go. A new bookmark called Export to layerling should appear there.

    Export to layerling

    Drag this button; clicking it on this page will not export a design.
Optional online bookmark: updates without replacing it

Experimental: drag Export to layerling (online) to your bookmarks bar once. It loads the currently published exporter each time you use it. Internet access is required; Tinkercad may block external scripts. If it is blocked, use the self-contained blue bookmark above.

Both bookmarks convert locally. The online bookmark requests code from this project's static website without sending design data.

Export a design

  1. Open your design in Tinkercad. Click Edit if you are looking at its preview page. Wait until you can see the design in the editor.
  2. Click the saved Export to layerling bookmark on your browser’s bar. If Tinkercad reloads the first time, wait for your design to reappear, then click the bookmark again.
  3. Wait for “Project ready.” Your browser downloads a file ending in .lyl, usually into your Downloads folder. If nothing downloads, click Download .lyl again in the small export panel.
  4. Open the file in layerling. On layerling’s start page, click Open a design or import geometry and choose the downloaded .lyl file. You can also drag the file into the layerling window.

For your next design, repeat only the steps under Export a design.

Large designs offer Export smaller assemblies or Keep one project. The assemblies option downloads one ZIP: extract it, read README.txt, then open a numbered .lyl in layerling. Whole construction groups and original positions are retained. Files are checked against Layerling’s reader limits. An indivisible group that cannot fit is preserved in needs-attention as a .preserved-project.zip, not labelled as a ready-to-open project. Nothing is discarded. Extract the outer ZIP before opening a project; that transport ZIP may be larger than Layerling’s per-project limit. Combining separate projects in layerling has not yet been verified.

Something not working?
  • The saved bookmark is missing: show the bookmarks bar again using the shortcuts above. If the bar has a menu at its right-hand end, check there for bookmarks that do not fit.
  • Firefox would not save the v0.2.3 bookmark: that version exceeded Firefox’s bookmark size limit. Refresh this page and drag the updated blue button onto the bookmarks bar. The current self-contained bookmark is built to fit that limit.
  • Clicking the bookmark asks you to open Tinkercad: switch to the tab containing your design’s editor, then click the saved bookmark there.
  • Geometry fails during export: export stops by default and creates no project. You can explicitly choose Continue without failed parts. Failed parts are omitted; if an operand inside a Boolean group fails, that whole group is omitted. The panel reports the omitted geometry count.
  • The file is missing: look in your Downloads folder, or use Download .lyl again while the export panel is still open.
  • Chrome shows “Out of memory”: reload the Tinkercad tab, then click the bookmark again. If your browser saved progress information, the panel offers Download failure report before another export. Send that report with your problem report. It contains progress and memory estimates, not design geometry or share links.
  • A detailed design appears as one colour in layerling: the colours may still be saved in the file. Layerling currently skips multicolour display for a grouped mesh above 300,000 triangles. Selecting the design and using Ungroup once may restore the colours by exposing smaller groups. Save a separate copy if you want to keep this change.
Updates, privacy and limits

Version {{VERSION}} preview. To update an older bookmark, drag the button onto your bar again, then remove the old bookmark so you know which one to use. Already installed bookmarks do not update themselves.

Your design is converted in your browser and is not uploaded by this tool. GitHub hosts this page and has its own hosting logs.

The panel displays its version and checks this project’s static website for a newer published version. The check sends no design data. It may be unavailable offline or blocked by the editor. “Run latest version” loads the published code for this run; it does not replace a self-contained bookmark. Install the optional online bookmark once for future updates without dragging again.

Small progress and memory records are saved in this browser to help diagnose interrupted exports. These records contain no design geometry, design names or share links.

Imported parts are editable meshes: you can move, resize and recolor them, but their original sketch settings are not recovered. This unofficial tool relies on Tinkercad editor features that can change. Large designs may need more memory.

The shortcuts above explain how to show each browser’s bar; they do not mean the importer has been tested in every browser. See compatibility and tested configurations.

Advanced troubleshooting

If a bookmark is awkward, copy the script and paste it into the editor’s console. For a JSON troubleshooting export, run exportTinkercadDesign() in the console after the bookmark has run.

When you are finished, run TinkerPower.delete("testkit") in that console to turn the editor tools back off.
